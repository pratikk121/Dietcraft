📲 If "Add to Home screen" didn't install:

Android Chrome requires local network IP addresses to be trusted as secure before it allows PWA installation:

  1. In Chrome on your phone, open: chrome://flags
  2. Search for "unsafely-treat-insecure-origin-as-secure"
  3. Paste the address above (http://...:8000), set to Enabled, and tap Relaunch.
  4. Now open DietCraft again and tap Install app!
🦊 Or simply use Firefox for Android: open the link, tap the ⋮ menu, and tap Install (Firefox installs directly without flags).
